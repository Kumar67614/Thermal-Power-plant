# 3D Thermal Power Plant Simulator

Run:
python -m pip install -r requirements.txt
python -m streamlit run app.py

The app uses Three.js from a CDN, so the browser needs internet access.

The 3D model includes the major boiler island, steam-water cycle, turbine-generator train, combustion/draft equipment, emission-control equipment, condenser/cooling system, feedwater equipment, ash handling and blowdown. Equipment is clickable and animated flow particles show the process path.
